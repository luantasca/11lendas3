## Regras de manutenção

1. Toda alteração relevante gera uma entrada em
   [REGISTRO-DE-ALTERACOES.md](REGISTRO-DE-ALTERACOES.md).
2. Toda decisão técnica não óbvia gera um novo ADR em
   [02-DECISOES-TECNICAS.md](02-DECISOES-TECNICAS.md).
3. O status das etapas é atualizado em
   [03-ROADMAP.md](03-ROADMAP.md) a cada entrega.
4. Nenhuma funcionalidade é documentada como existente se não estiver
   implementada e testada.
